# admin.project-42.dev

The owner administration console for a Project 42 instance.

This repository had no README until 2026-08-03. A public repository with no
statement of purpose invites the wrong contribution.

## What this is

Operational control of a hosted instance: the surface an operator uses to run
the platform.

## What this is not

It is **not** a learner surface and must never become one. It does **not**
author content; that is `orchard`. It is **not** where credentials live, and
this is the repository most likely to be handed one by mistake. This repository
is public.
